SAMPLE CODE

認可コード + PKCE

フローデモが実行している、認可コードへの challenge の紐付けと、コード交換時の verifier 検証を読めます。

このコードはブラウザ内のシミュレーションです。利用者は固定の demo-user で、通信境界・ログイン認証・永続ストレージは提供していません。

ローカルで試す

npm run build:pages
python3 -m http.server 8000 --directory dist

http://localhost:8000/samples/pkce/ を開いて操作します。下のプロトコルコードがコードの発行・検証を担当し、クライアントコードが state の確認と各段階の表示を担当します。
