認可コード + PKCE

ブラウザ内デモと Workers は、コードへの challenge の紐付けと交換時の検証ロジックを共有します。

Workers では Durable Objects のトランザクションで、コードの検証・消費・トークン保存を原子的に行います。利用者は固定の demo-user で、ログイン認証は省略しています。実運用の認可サーバーとして公開するための実装ではありません。

Workers で実際の HTTP フローを動かす

npm ci
npm run dev
# 別ターミナル
node examples/pkce-client.mjs --approve

/authorize を開いてデモ利用者として同意すると、認可コードと state を付けて登録済みの https://client.example/callback へリダイレクトします。このホストは説明用で、クライアントアプリはホストしていません。上記の Node.js クライアントは Location を取得し、クライアント側の state 検証・コード交換・リソース取得を行います。
