Ephemeral Subject Identifier

実際にデモが使うプロトコル処理と表示コードです。認証要求ごとのsub発行を、PKCEのコード交換・RS256署名付きID Token・UserInfoと組み合わせています。

OP・RPを同じブラウザ内で動かす学習用モデルです。ネットワーク境界、実ログイン、実年齢の保証、鍵・発行履歴の永続化は提供しません。アプリ固有の年齢クレームを、このOpenID仕様が定義するものとして扱わないでください。

ローカルで動かす

npm ci
npm run test:ephemeral
npm run build:pages
python3 -m http.server 8000 --directory dist

http://localhost:8000/samples/ephemeral-subject/ を開きます。32バイトのWeb Crypto乱数をbase64urlにし、OPのページ内履歴で再利用を拒否します。発行履歴の永続化や本番OPの設計は 説明ドキュメントを参照してください。
